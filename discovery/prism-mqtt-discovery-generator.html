Silla Prism MQTT discovery generator

Builds a Home Assistant script that publishes MQTT device discovery through mqtt.publish. An example automation that can run the script at startup is shown separately.

  1. Copy or download the script YAML.
  2. Paste it into scripts.yaml (omit the top-level script: key if that file is already included), or merge it into configuration.yaml.
  3. Reload scripts, then run the script once to publish discovery.
  4. Do not use this together with the custom silla_prism integration on the same serial.
  1. Copy the script YAML (it starts at sequence:).
  2. In Home Assistant go to Settings → Automations & scenes → Scripts.
  3. Select Create script, then the three-dots menu → Edit in YAML.
  4. Replace the editor contents with the generated script and save.
  5. Run the script once to publish discovery. Do not use it together with the custom silla_prism integration on the same serial.
